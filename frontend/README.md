# Pre-Delinquency Risk Frontend

React/Vite dashboard for the Pre-Delinquency Risk Intelligence API.

## Local Development

```bash
npm install
npm run dev
```

Set the API URL in `.env.local`:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Production

For Vercel, set:

```text
VITE_API_BASE_URL=https://your-render-service.onrender.com
```

Build command:

```bash
npm run build
```
